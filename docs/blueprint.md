# **App Name**: Prodify

## Core Features:

- User Authentication: Secure login/registration page, capturing name, age, and email. Generates a unique alphanumeric user ID upon account creation.
- Motivation Capture: A dedicated page post-registration to capture the user's reason for using Prodify.
- Dashboard UI: Main dashboard with a left-side navigation panel and a main content area. Includes a welcome message and an anime character.
- User Profile: Section for users to enter/view their details (name, age) and Prodify score, reflecting their productivity.
- Left-Side Navigation Panel: Having sections like profile, productivity tracker, techniques, books, tasks, history, settings.

## Style Guidelines:

- Primary color: Light violet (#D8BCFF), for a calming and productive feel.
- Background color: Very light violet (#F8F6FF).
- Accent color: Blue-violet (#A385D6) for a professional yet friendly vibe.
- Font: 'PT Sans', a humanist sans-serif, will be used for headlines and body text due to its combination of modern aesthetic and warm personality.
- Use consistent and clear icons for navigation items.
- Clean, well-structured layout with a sidebar for navigation.
- Subtle animations to indicate successful account creation and data updates.
